[arXiv260518] ParamSpMM: Adaptive and Efficient Sparse Matrix-Matrix Multiplication on GPUs for GNNs

arXiv

Authors
Lixing Zhang, Guanhua Ye, Hongzheng Li, Shigang Li, Yingxia Shao
Institution
Beijing University of Posts and Telecommunications

The paper introduces ParamSpMM, a parametric approach for efficient and adaptive SpMM computation on GPUs for GNNs. Authors
Dzung Pham, Kleomenis Katevas, Ali Shahin Shamsabadi, Hamed Haddadi
Institution
University of Massachusetts Amherst, Brave Software, Imperial College London

The paper introduces AgentStop, a lightweight efficiency supervisor that uses low-cost signals like token-level log probabilities to predict and preemptively terminate LLM agent trajectories unlikely to succeed, reducing wasted energy on consumer devices. The work highlights predictive early termination as a practical mechanism for sustainable, privacy-preserving local LLM agents.

Authors
Himanshu Singh Baghel
Institution
J.C. Bose University of Science and Technology

The paper introduces ADAPT, an online exponentially weighted moving average (EWMA) estimator that dynamically tracks container cold-start duration at runtime, feeding a dynamic planning horizon into a Model Predictive Controller (MPC) for proactive autoscaling. Evaluated on three policies and six workload archetypes, the MPC+LSTM combination achieved below 5% SLA violations across all workloads, outperforming both reactive HPA (7–19%) and MPC+Prophet (up to 28.7% on bimodal traffic).

[arXiv260518] A Few GPUs, A Whole Lotta Scale: Faithful LLM Training Emulation with PrismLLM

arXiv
mlsysllm trainingLLM training emulation, execution graph, slicing-based approach, hybrid emulation, virtual participants, performance reproduction, GPU cluster
Authors
Shaoke Xi, ChonLam Lao, Boyi Jia, Jiaqi Gao, Zhipeng Zhang, Jiamin Cao, Brian Sutioso, Erci Xu, Minlan Yu, Kui Ren, Yong Li, Zhengping Qian, Ennan Zhai, Jingren Zhou
Institution
Alibaba Group, Harvard University, Shanghai Jiao Tong University, Zhejiang University

PrismLLM decouples large-scale LLM training execution from the need for large GPU clusters by constructing a high-fidelity execution graph via a slicing-based approach and performing hybrid emulation, where selected ranks run the original program while others are replayed as virtual participants. Experiments show that PrismLLM accurately reproduces performance and memory behavior, achieving only 0.58% average error in iteration time and less than 0.01% error in peak GPU memory usage. It can emulate clusters of up to 8192 GPUs using fewer than 1% of the physical GPUs required by the original deployment.

[arXiv260518] On the Fragility of Data Attribution When Learning Is Distributed

arXiv
mlsysothersdata attribution, distributed training, latent optimization, non-IID data, marginal-utility evaluators, attribution-first attack, geometry-based defenses
Authors
Xian Gao, Bo Hui, Min-Te Sun, Wei-Shinn Ku
Institution
Auburn University, University of Tulsa, National Central University

This paper reveals the fragility of data attribution in distributed learning by introducing an attribution-first attack that uses latent optimization to inject small synthetic batches, inflating the adversary's attribution value while maintaining global utility. The attack exploits non-IID label coverage and evaluator sensitivities across datasets and models, consistently reshaping the attribution structure among benign clients without degrading accuracy. The findings highlight that data attribution itself can be attacked, motivating the need for attribution-robust and incentive-compatible scoring mechanisms.

The paper introduces Asteria, a runtime system that makes second-order optimization practical for LLM training by offloading optimizer state to CPU memory and NVMe storage, and by computing inverse-root operations asynchronously on the host.
