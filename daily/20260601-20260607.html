[arXiv260601] Federated Variational Preference Alignment with Gumbel-Softmax Prior for Personalized User Preferences

arXiv
aipersonalized federated learningvariational preference learning, Gumbel-Softmax, federated mixture prior, orthogonal loss, preference prototypes
Authors
Jabin Koo, Hoyoung Kim, Minwoo Jang, Jungseul Ok
Institution
POSTECH, National AI Research Lab

The paper proposes FedVPA-GP, a federated learning framework for aligning large language models with diverse user preferences while preserving privacy. It addresses posterior collapse by introducing a Federated Mixture Prior that uses aggregated population distributions and an Orthogonal Loss to separate preference prototypes. Experiments on HH-RLHF show that FedVPA-GP successfully disentangles conflicting user intents and enables dynamic preference switching, outperforming monolithic baselines.

[arXiv260601] Polynomial Histograms for Memory-Efficient Representation of Long-tailed System Distributions

arXiv
sysdistributed systems monitoringpolynomial histograms, information loss metric, moment annotations, memory-efficient representation, binned data, long-tailed distributions
Authors
Murray Stokely, Tim Hesterberg, Arif Merchant, Nate Coehlo
Institution
Google, Inc.

This paper introduces polynomial histograms, which annotate each bin with moments of the underlying distribution to reduce memory usage while preserving information, compared to traditional histograms with more bins. They propose an information loss metric for binned data to optimize the trade-off between storage cost and fidelity. The technique is applied to file system metrics in a large production system, showing that polynomial histograms can offer more information at lower storage cost.

[arXiv260601] Kernel Foundry: A Diagnosis-driven Evolutionary Kernel Optimizer with Multi-Experts

arXiv
mlsysGPU kernelsevolutionary optimization, retrieval-augmented generation, multi-island search, diagnostic feedback, experience library
Authors
Zixuan Huang, Da Chen, Kecheng Huang, Lihao Yin, Xing Li, Huiling Zhen, Mingxuan Yuan, Zili Shao
Institution
The Chinese University of Hong Kong, Huawei Noah's Ark Lab

Kernel Foundry is a diagnosis-driven evolutionary framework that optimizes GPU kernels by combining expert-guided, retrieval-augmented initialization with a multi-island evolutionary search. It iteratively refines kernels using structured diagnostic feedback and accumulates reusable optimization knowledge in a centralized experience library. Experiments on KernelBench demonstrate that it consistently improves both correctness and performance, achieving up to 100% correctness on Level 2.

DG-CoLearn proposes a collaborative dynamic graph learning framework that uses incremental graph snapshot processing to focus computation on updated regions, reducing computational overhead. Authors
Aditya K Kamath, Arvind Krishnamurthy, Marco Canini, Simon Peter
Institution

The paper introduces Invariant Bit Packing (IBP), a novel lossless compression algorithm that identifies and eliminates invariant bits across groups of tensors to reduce PCIe transfer bottlenecks in ML pipelines. By leveraging GPU-optimized warp parallelism, low-overhead bit operations, and asynchronous PCIe transfers, IBP achieves significant speedups—74% faster GNN training, 180% faster DLRM embedding lookup, and 24% faster LLM inference—without the accuracy loss of lossy compression.

[arXiv260601] Energy-Efficient Aggregation and Minimum-Degree Spanning Trees in Radio Networks

arXiv
sysdistributed algorithmsrandomized distributed algorithm, spanning tree, energy complexity, radio networks, aggregation schedule, minimum-degree spanning tree
Authors
Yi-Jun Chang, Yang Ze Guan
Institution
National University of Singapore

This paper presents a randomized distributed algorithm for energy-efficient aggregation in multi-hop radio networks, achieving near-optimal energy complexity. The algorithm constructs a spanning tree whose maximum degree is within O(log n) of the optimal, and it computes the aggregate in O(n polylog n) rounds while using O(Δ* polylog n) energy, where Δ* is the minimum possible maximum degree of any spanning tree. The method is nearly optimal as any aggregation schedule requires at least Δ* rounds of awake time for some node.

Authors
Haymo Kutschbach
Institution

The paper introduces a self-optimizing virtual processor (VP) for numerical array programs that automatically parallelizes sequential code using a decentralized network of cooperative execution segments, which make local decisions on task placement and data movement without a central scheduler. This approach preserves sequential semantics while exploiting parallelism across large program regions, targeting low-latency strong scaling on heterogeneous hardware. The current implementation is for the ILNumerics.ONAL domain-specific language but is broadly applicable to array-based languages like MATLAB and NumPy.

[arXiv260601] Memory-Bound but Not Bandwidth-Limited: The Physical AI Inference Gap in Batch-1 LLM Decode

arXiv
mlsysllm inferencebatch-1 decode, memory bandwidth, CUDA Graphs, quantization, GQA transformers, context length, GPU inference
Authors
Josef Chen
Institution
KAIKAKU

This paper studies batch-1 autoregressive decode for physical AI inference, showing that while the workload is memory-bound, faster HBM bandwidth does not proportionally reduce latency due to launch-side overhead, which is isolated via CUDA Graphs experiments. The authors measure at context lengths from 2048 to 16384 across four NVIDIA GPUs and find that quantization efficiency varies significantly depending on runtime support, with GPTQ+ExLlamaV2 achieving the best speedup. The key conclusion is that memory savings only translate to latency improvements when the runtime effectively realizes them.
