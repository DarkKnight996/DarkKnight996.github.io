[arXiv260803] DeltaServe: Host-Agnostic Co-Serving of Inference and Fine-Tuning for LLMs

arXiv
mlsysllm inferenceLoRA fine-tuning, multi-LoRA batching, SLO-aware scheduling, CUDA graphs, latency model, co-serving
Authors
Jiaxuan Chen, Jianshu She, Ye Yuan, Rajat Ghosh, Karan Gupta, Qirong Ho, Xue Liu, Oana Balmau
Institution
McGill University, MBZUAI, Nutanix Inc.

DeltaServe proposes a host-agnostic co-serving design that utilizes idle GPU capacity during inference to run LoRA fine-tuning tasks while maintaining inference service-level objectives. It introduces an SLO-aware scheduler guided by a CUDA-graph-aware latency model, integrated with vLLM, SGLang, and S-LoRA. Evaluation on a production trace shows up to 2.9x higher fine-tuning throughput than LLMStation with full SLO compliance.

The paper presents Knox, a system for safety checking in IoT-enabled smart spaces, introducing a new language for safety specifications and two static verification algorithms that check multiple safety properties across concurrent routines. [arXiv260803] Characterizing LLM Kernel Access and Memory Interaction in Multi-Partition NUMA GPUs

arXiv

Authors
Donghyeon Joo, Sooraj Puthoor, Nuwan Jayasena, Bahar Asgari
Institution
University of Maryland, College Park; AMD

The paper analyzes memory access patterns of LLM kernels on multi-partition NUMA GPUs, introducing a memory trace analysis methodology to derive workgroup-level sharing behavior and evaluating latency impacts with a cycle-level simulator. It categorizes kernel operands into three inter-workgroup sharing patterns (global, partial, private) and shows that optimization strategies must differ across categories, advocating for placement-aware kernel programming and architectural support to improve locality in multi-partition GPUs.

Authors
Cosmin E. Oancea, Stephen M. Watt
Institution
University of Copenhagen, University of Waterloo

This paper presents high-level implementations of big integer arithmetic (addition, subtraction, multiplication, division) for GPU using the functional language Futhark, targeting mid-size integers of 2^15 to 2^19 bits. Comparing against hand-written C++/CUDA and CGBN, the authors identify that automated array placement in GPU register memory is critical for performance, and show that high-level code can approach competitive performance with appropriate compiler improvements.

Authors

Institution

The paper introduces Aries, a full-stack experimentation framework for agentic LLM serving that separates task semantics from execution configurations and correlates system telemetry with agent trajectories. Through reproducible experiments and production traces, the authors find that token-centric metrics miss non-inference bottlenecks, excessive context retention yields diminishing accuracy while reducing serving capacity, and current sandbox snapshot management makes aggressive suspension costly. They advocate for agent-native serving systems with trajectory-level metrics, adaptive context management, elastic sandbox resources, and minimized sandbox attack surfaces.

Authors

This paper proposes the Organizational Consensus Algorithm (OCA), a mechanism design framework for consensus among self-interested, boundedly rational departmental agents under information asymmetry. Authors

Institution

The paper introduces LayoutBench, a benchmark for evaluating cloud storage layouts for multimedia ML datasets, comparing individual objects (L1), tar archives (L2), and Parquet columns (L3) in terms of retrieval time, data transferred, and cost. Institution

The paper proposes a lightweight global termination detection algorithm for distributed betweenness centrality computation, allowing vertices to locally determine when the entire system has converged. Authors

Institution

This paper proposes GQ-FSL, a green quantized federated split learning framework that applies stochastic quantization to both local collaborative training and wireless transmissions, with asymmetric precision levels for client- and server-side submodels. [arXiv260803] SLIM: Saturation-Aware Lightweight Performance Modeling for LLM Serving

arXiv
mlsysllm inferenceperformance modeling, attention kernels, DRAM bandwidth saturation, batch size optimization, throughput latency trade-off, KV cache memory, GPU profiling
Authors
Pol G.Recasens, Ferran Agullo, Yue Zhu, Chen Wang, Jordi Torres, Josep Ll. Berral
Institution
Barcelona Supercomputing Center (BSC), Universitat Politècnica de Catalunya - BarcelonaTech (UPC), IBM Research

This paper presents SLIM, a semi-analytical performance model for LLM inference that predicts throughput and latency based on Transformer computation and memory traffic, and introduces the Batching Configuration Advisor (BCA) to select optimal batching configurations under latency constraints. Through GPU profiling, the authors identify that throughput saturation arises from DRAM-bandwidth limits in attention kernels during the decode phase—driven by near-constant arithmetic intensity as context lengths grow—and demonstrate that SLIM outperforms baselines while enabling up to 55 GB of avoidable GPU memory allocation.
