[arXiv260817] Adaptive Snapshots Require Visible Reads

arXiv
sysdistributed systemssnapshot, linearizability, shared memory, invisible reads, adaptive snapshots
Authors
Niv Sulimany, Tomer Cory, Erez Petrank
Institution
Technion – Israel Institute of Technology

The paper investigates the possibility of building adaptive snapshots with invisible reads, showing that such implementations are not linearizable even in the single-writer, single-scanner setting. It concludes that all existing adaptive snapshot implementations require visible reads, contradicting the hope for improved performance via invisible read operations.

[arXiv260817] Large-scale workflow placement in serverless computing using integer nonlinear programming

arXiv
sysoptimal schedulinginteger nonlinear programming, serverless computing, workflow placement, decomposition strategy, edge computing
Authors
Joshua Adamek, Natalie Carl, Trever Schirmer, Moritz Heinlein, David Bermbach, Sergio Lucia
Institution
Technische Universität Dortmund, Technische Universität Berlin

The paper proposes a novel integer nonlinear programming model for deploying large workflows in serverless edge computing, minimizing user monetary costs and workflow evaluation times. A decomposition strategy is introduced to scale toward many cloud/edge nodes and handle decomposed node attribute knowledge. Case studies show the decomposition approach scales well and improves deployment by a mean of 10% over a simple heuristic.

Authors

Institution

The paper proposes using model partitioning in federated learning to shift energy consumption between participants based on carbon or grid signals, aiming to make FL more sustainable. Preliminary experiments show that partitioning can reduce a participant's energy consumption by up to 76% without significant overhead, offering a promising direction for sustainable cross-silo FL.

[arXiv260817] Balancing Workload Performance and Slurm Stress: Four Nextflow Deployment Strategies

arXiv
sysworkflow management systemsNextflow, Slurm, job arrays, HyperQueue, Flux, RPC demand, workload benchmarking, LASTZ, clean-start clock, sdiag counters
Authors
Nil Tianchen Mu, William Dizon, Glen Otero, Torey Battelle
Institution
Arizona State University

This paper presents a reproducible measurement protocol for comparing four Nextflow deployment strategies on shared Slurm clusters, focusing on walltime and RPC demand trade-offs. Using a clean-start clock and per-user sdiag counters, they evaluate native Slurm, job arrays, HyperQueue, and Flux, finding that arrays and HyperQueue achieve faster turnaround while Flux reduces scheduler RPC load, with results varying by cluster.

mlsysothersfederated learning, quantum-inspired Kolmogorov-Arnold networks, autoencoder, ECG classification, parameter efficiency, communication cost
Authors

Institution

[arXiv260817] Validating LLM-Modernized Scientific Software Through Differential Fault Injection

arXiv
mlsysfault-tolerancefault injection, differential testing, LLM code generation, scientific software modernization, self-consistent field, GAMESS, silent data corruption, parallel deadlock, reduced precision
Authors
Evan Coleman, Yuzhong Shen, Masha Sosonkina, Peng Xu
Institution
University of Mary Washington, Old Dominion University, Ames National Laboratory, Iowa State University

This paper proposes a differential fault-injection validation method to assess whether LLM-modernized Fortran kernels in GAMESS preserve off-nominal behavior (faults, perturbations, reduced precision) compared to the original code. Across over 2,200 runs, the method characterizes transient-fault absorption, persistent perturbation effects, parallel deadlocks, and false convergence, and shows that original and modernized kernels match in all paired injection tests. The results support differential fault injection as a practical tool for evaluating resilience fidelity in AI-assisted scientific software modernization.

[arXiv260817] Rollplex: Cross-Phase GPU Spatial Sharing for Vision Language Model Post-Training

arXiv
mlsyspost-trainingGPU spatial sharing, tensor parallelism, memory management, reinforcement learning, vision language model, HBM residency, weight sharing, synchronous on-policy RL
Authors
Hanfeng Lu, Tianyu Feng, Suyi Li, Yuheng Zhao, Wei Gao, Shaopan Xiong, Ju Huang, Siran Yang, Jiamang Wang, Lin Qu, Wei Wang
Institution
Hong Kong University of Science and Technology (HKUST), Alibaba Inc

Rollplex is a runtime that improves vision-language model post-training by overlapping prefix computation with rollout decoding across GPU spatial sharing, avoiding serial phase execution. It uses phase-aware memory management and parallelism-aware weight sharing to reduce HBM and avoid duplicate actor copies, achieving 1.23–1.30× speedup over serial colocation and 1.57–2.24× over disaggregation on 32 H800 GPUs while preserving synchronous RL updates.

[arXiv260817] A Barrier-Free Synchronization Algorithm for Multi-Engine AI Accelerators

arXiv
syscompiler and synchronizationsemaphore allocation, barrier elimination, bisimulation, formal verification, Lean proof assistant, multi-engine AI accelerators, loop synchronization, dynamic thresholds, compiler backend
Authors
Chungha Sung, Nikil V. Shyamsunder, Hanliang Zhang, Daniel Kroening, Joonwon Choi
Institution
Amazon, Inc., Cornell University

The paper presents a barrier-free synchronization algorithm for multi-engine AI accelerators (like AWS Trainium) that replaces all-engine barriers in loops with precise, per-dependency wait conditions using runtime-computed dynamic thresholds from loop iteration counts. Implemented in the AWS Neuron compiler, the approach reduces latency by 10–45% on ML kernels, achieves a 3.3x speedup on a synchronization-bound microbenchmark, and is formally verified in the Lean proof assistant to meet the minimum synchronization required for correctness.
