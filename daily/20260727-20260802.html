[arXiv260727] Agentic CPU-GPU Scheduling for Heterogeneous AI Workloads

arXiv
mlsysllm inferenceheterogeneous scheduling, agentic AI, LLM-based scheduling, GPU memory management, runtime monitoring, DAG execution
Authors
Tianxi Lu, Sherief Reda
Institution
Brown University

The paper proposes an agentic scheduler that combines an LLM agent with an algorithmic runtime monitor to assign heterogeneous AI tools to GPU or CPU, considering VRAM constraints and runtime contention. It profiles 19 tools and achieves optimal device mapping in all 13 test scenarios, outperforming existing baselines like HEFT, StarPU, and the all-GPU policy without offline training.

This paper proposes a decentralized confidential computing platform utilizing Intel TDX and NVIDIA Confidential Computing to create encrypted Confidential Virtual Machines (CVMs). [arXiv260727] FBLayout: Optimizing Memory Layout for Efficient LLM Finetuning on Mobile GPUs

arXiv
mlsysllm trainingmemory layout optimization, tile-based index transformation, activation-guided layout selection, attention mechanism, mobile GPUs
Authors
Kahou Tam, Wei Niu, Yu Bao, Xiaomin Ouyang, Chengzhong Xu, Li Li
Institution
University of Macau, University of Georgia, Hong Kong University of Science and Technology

FBLayout proposes a layout-aware framework for efficient LLM fine-tuning on mobile GPUs, addressing memory constraints and layout transformation overhead in attention mechanisms. It introduces a unified R-Tile layout, tile-based index transformation to avoid data movement, and activation-guided layout selection to propagate efficient layouts. Evaluations on various mobile GPUs show 2.2-5.7x speedup over existing frameworks, enabling practical on-device model fine-tuning.

[arXiv260727] NUMA balancing hampering performance of spiking network simulations

arXiv
sysHPC system optimizationNUMA balancing, spiking network simulation, energy efficiency, jemalloc, performance variability
Authors
Melissa Lober, Alp Inangu, Gorka Peraza Coppola, Dennis Terhorst, Sebastian Gillessen, Jan Vogelsang, Hans Ekkehard Plesser, Brian Wylie, Benedikt Steinbusch, Guido Trensch, Susanne Kunkel, Markus Diesmann
Institution
Jülich Research Centre, RWTH Aachen University, Norwegian University of Life Sciences

The paper demonstrates that disabling automatic NUMA (Non-Uniform Memory Access) balancing can reduce energy consumption by 30% for large-scale spiking network simulations, without affecting result correctness. The authors developed a time- and compute-node resolved performance display to reveal fine-grained temporal variability caused by NUMA balancing interacting with thread-aware memory allocation. As a result, they provided users the option to toggle NUMA balancing per job, enabling researchers to optimize performance for their specific applications.

The paper introduces PRISM, a workload-reproducing evaluation framework for assessing POSIX storage systems in AI research clusters, focusing on usability and performance rather than peak throughput. [arXiv260727] Accountable Transaction Inclusion Lists: Enhancing Ethereum's Censorship Resistance

arXiv
sysblockchain, censorship resistanceinclusion lists, accountability, Fair Forward Inclusion Lists, Ethereum, MEV, block builder
Authors
Patrick Spiesberger, Hannes Hartenstein
Institution
Karlsruhe Institute of Technology

The paper proposes FairFIL, an accountable censorship resistance mechanism for Ethereum that requires block builders to publicly disclose all censored transactions, with a committee verifying completeness and the next builder forced to include them under penalty of forfeiting the full block reward. The mechanism raises multi-block censorship costs by an order of magnitude compared to existing proposals like FOCIL, while preserving the builder's freedom for MEV extraction. Empirical evaluation on Ethereum mainnet shows that the required mempool consistency is met in practice, making compliance rational for all participants.

Authors

Institution

SPDP unifies static and dynamic pruning to accelerate LLM inference on GPUs. It introduces a Tiled-Column-wise Bitmap Compressed format and complementary CUDA and Tensor-Core kernels that harmonize static weight removal with input-adaptive activation skipping. Evaluations show SPDP achieves up to 2.51x speedup over the state-of-the-art SpInfer framework while matching perplexity with 25% higher sparsity.

Authors
Woosuk Choi, Seungmo Kim
Institution
Chung-Ang University, Georgia Southern University

This paper proposes a dual-layer blockchain decentralized application (dApp) that uses IPFS for off-chain storage and anchors content identifiers and metadata on-chain to make aircraft maintenance records tamper-evident and trustworthy. The architecture reduces on-chain overhead to constant complexity and, in a 7-kB test on BNB Smart Chain, achieved 93.9% gas savings compared to direct on-chain storage. An economic framework is also presented, suggesting potential audit-cost savings of over 90% under stated assumptions.

Institution

Molt introduces a compact, PyTorch-native training framework designed to simplify and accelerate agentic reinforcement learning research while maintaining full performance. [arXiv260727] TileSight: A First-Principles Tile-Centric Analytical GPU Performance Model from Cores to Clusters

Authors

Institution

TileSight is a first-principles analytical GPU performance model that uses tiles as the central abstraction to model compute-memory overlap, cache hierarchy, and inter-GPU communication. The model outperforms state-of-the-art baselines and can guide tile-configuration optimization competitively with expert and vendor baselines.
