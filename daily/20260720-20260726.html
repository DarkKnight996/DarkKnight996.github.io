[arXiv260720] The Honest Quorum Problem: Epistemic Byzantine Fault Tolerance for Agentic Infrastructure

arXiv
sysfault-toleranceByzantine fault tolerance, consensus, epistemic fault, state machine replication, post-deterministic distributed system, quorum
Authors
Jun He, Deying Yu
Institution
OpenKedge.io

The paper defines the Honest Quorum Problem, a failure mode where protocol-compliant agentic validators endorse semantically invalid state transitions due to reasoning errors, termed epistemic faults. It introduces Epistemic Byzantine Fault Tolerance (EBFT), a model that augments the Byzantine fault bound with confidence-indexed quantities to characterize semantic safety risk and liveness degradation independently. The work derives quorum-threshold conditions for semantic validity and liveness, and shows that adding more agents improves fault tolerance only when it measurably reduces correlated invalid endorsements.

This paper addresses latency bottlenecks in GPU collective communication for latency-sensitive workloads like long-context LLM inference. SQUIRO introduces a framework for security-aware scheduling of hybrid quantum-classical workloads on Kubernetes, combining a Unified Scheduling Model with a six-step design methodology. [arXiv260720] Rendering 3D Gaussians on a Graph Processor

arXiv
mlsysGPU kernels3D Gaussian Splatting, Bulk Synchronous Parallel, tile-based rendering, inter-tile communication, SRAM-only architecture, workload imbalance
Authors
Nicholas Fry, Ignacio Alzugaray, Mark Pupilli, Paul H. J. Kelly, Andrew J. Davison
Institution
Imperial College London

The paper presents the first implementation of a 3D Gaussian renderer on Graphcore's IPU, which has 1,472 independent tiles with only on-chip SRAM, approximating efficient sensor-processor architectures. Gaussians are routed to destination tiles via Manhattan-distance hops on a NEWS grid, then propagated to overlapping neighbors, exploiting spatial and temporal locality. The evaluation identifies key bottlenecks such as inter-tile bandwidth, SRAM capacity, and non-uniform Gaussian density, suggesting that direct inter-SM communication in GPUs could reduce DRAM access.

[arXiv260720] FSZ: Breaking the Prediction-Throughput Trade-off in GPU Lossy Compression

arXiv

Authors
Jiajun Huang
Institution
University of South Florida

FSZ is a GPU error-bounded lossy compressor that breaks the inherent trade-off between prediction accuracy and throughput. It introduces three co-designed innovations—cross-block prediction, per-tile adaptive multi-order prediction, and a single-pass four-way evaluation—within a single CUDA kernel. On an NVIDIA GH200 GPU, FSZ achieves state-of-the-art compression ratios (up to 10.95x better than cuSZp-P) while simultaneously attaining the highest average throughput (676 GB/s compression, 785 GB/s decompression).
