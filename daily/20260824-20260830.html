[arXiv260824] MEMPOWER: Efficient Power Management with Fine-grained Memory Analysis and Modeling for HPC Workloads

arXiv
syspower managementDVFS, memory trace analysis, binary instrumentation, cost model, energy-delay product
Authors
Nanda Velugoti, Joseph Manzano, Andres Marquez, Nathan Tallent, Kyle Hale
Institution
Oregon State University, Pacific Northwest National Laboratory

MEMPOWER is a model-based framework that profiles fine-grained memory access behavior of HPC workloads to statically instrument binaries with optimized voltage/frequency transitions. Institution

The paper introduces Scalpel3, an open-source, massively parallel file carving framework for recovering both contiguous and fragmented files from raw storage media. The framework aims to lower barriers for developing and deploying carving strategies in digital forensics and data recovery.

[arXiv260824] TreeWY: Speculative Verification for Gated DeltaNet Hybrids

arXiv
mlsysllm inferencespeculative decoding, gated delta net, WY transform, tree-structured verification, memory optimization, recurrent state compression, HBM reduction, TTFT optimization
Authors
Sneha Murthy Ghantasala
Institution
Thomson Reuters

This paper introduces TreeWY, a speculative decoding verification method for hybrid models with Gated DeltaNet layers that removes per-node recurrent state snapshots by using a tree-structured WY transform. It computes all draft nodes' outputs with a single triangular solve and reconstructs only the accepted state on commit, storing a small pseudo-value matrix. This significantly reduces memory and KV-cache pressure, improving throughput and time-to-first-token for memory-bound serving scenarios, and enables wider speculative draft trees.

Institution

This paper evaluates the portability and performance of Fortran's 'do concurrent' construct for GPU acceleration across NVIDIA, AMD, and Intel GPUs using a production finite-difference application, comparing pure standard-language offloading against augmenting with directives like OpenMP. The paper extends the im2win convolution paradigm to support multi-precision execution on GPUs, implementing full-precision kernels on CUDA cores and half-precision kernels on tensor cores with optimizations like zig-zag memory access and asynchronous data movement.
